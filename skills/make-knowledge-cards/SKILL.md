# Make Knowledge Cards

把用户粘贴的文章或本地 Markdown/TXT 文件转换成 5~8 张知识卡片。目标是提炼“真正重要”的知识，而不是复述全文。

## 输入与边界

- 支持：用户直接粘贴的文本 / Markdown 文本；本地 `.md` / `.txt` 文件（先读取全文再处理）。`.md` 中的格式符号（如 `#`、`-`、`` ` ``）不是内容，忽略不计。
- 不支持：网页 URL、PDF、图片、Anki 格式、图形界面。遇到此类输入，直接说明不支持，并请用户粘贴文本或提供 `.md` / `.txt` 文件；不要自行抓取网页或转换格式。
- 多输入：若用户一次提供多篇文章或文件，逐篇各生成一组卡片，每组 5~8 张，组间用文章标题区分。

## 工作流程

1. **通读全文**：理解文章主旨、结构和逻辑顺序。
2. **提取候选知识点**：只保留真正重要的信息——
   - 概念与定义
   - 机制、原理与因果关系
   - 关键结论与数据
   - 步骤、流程与方法
   - 易混淆点 / 易错点
   丢弃：铺垫、修辞、重复论述、例子堆砌、广告或与主题无关的内容。
3. **去重**：同一知识点（包括换说法复述、分散在多处论述的）合并为一张卡片。
4. **切分与排序**：一张卡片只讲一个知识点；按原文逻辑顺序排列卡片。
5. **控制数量**：默认输出 5~8 张。
   - 候选知识点超过 8 个：按对理解主题的重要程度排序，只保留最重要的 8 个。
   - 信息不足（原文很短或知识点少于 5 个）：输出实际数量的卡片，并在开头注明“本文信息量有限，共 N 张卡片”，不要强行凑数。

## 卡片格式

每张卡片包含四个字段，顺序固定：

- **标题**：用原文术语，简洁概括这个知识点（不超过 20 字）。
- **核心知识**：一句话给出最关键、最确定的结论。
- **简明解释**：2~4 句，用自己的话讲清逻辑，不引入原文未提供的信息。
- **例子或自测问题**：二选一——优先给一个具体例子；若原文没有现成例子且无法由原文直接推出，则改为一个自测问题（如“请解释……”或“……和……有什么区别？”）。

## 输出模板

```markdown
# 知识卡片：<文章主题>

## 卡片 1：<标题>
- **核心知识**：<一句话结论>
- **简明解释**：<2~4 句>
- **例子或自测问题**：<例子或问题>

## 卡片 2：<标题>
……
```

只输出知识卡片本身（可含开头的信息量说明），不附加总结、评价或建议。

## 质量标准（违反任一即返工）

- 一张卡片只讲一个知识点；多个知识点拆开，不可合并成“大杂烩”卡片。
- 卡片之间不重复；同一信息只出现一次。
- 不编造：卡片中的每个概念、数字、结论都必须能在原文中找到依据；例子若不在原文中，必须能由原文直接推出，否则改用自测问题。
- 数字、专有名词与原文完全一致，不得改写或约化。
- 数量 5~8 张；信息不足时不凑数，超量时按重要性裁剪。
- 语言与原文一致（原文中文则输出中文）。
