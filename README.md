# make-knowledge-cards

把用户粘贴的文章或本地 Markdown/TXT 文件转换成 **5~8 张知识卡片** 的学习型 Skill。每张卡片包含**标题、核心知识、简明解释、例子或自测问题**，适合学习、复习与卡片笔记。

## 项目解决什么问题

读长文后信息过载、抓不住重点，是常见的学习痛点。本项目的目标是：

- **把文章变成可复习的卡片**：自动提炼 5~8 个真正重要的知识点，而不是复述全文。
- **解决“读完就忘”**：每张卡片自带一个例子或自测问题，可直接当复习材料使用。
- **解决笔记工具的两大通病**：要么照搬全文（没有提炼），要么自由发挥（脱离原文）。本 Skill 严格忠于原文：不编造、自动去重、信息不足时不强行凑数量。

## 主要功能

- **输入**：用户直接粘贴的文章文本；本地 `.md` / `.txt` 文件。
- **输出**：5~8 张知识卡片，每张包含四个字段——标题、核心知识、简明解释、例子或自测问题。
- **只提取重要知识**：优先保留概念定义、机制原理、关键结论与数据、步骤流程、易错点；丢弃铺垫、修辞、重复论述与无关内容。
- **一张卡片一个知识点**：不合并成“大杂烩”卡片。
- **自动去重**：同一知识点（包括换说法复述的）只出现一次。
- **不编造**：卡片中的每个概念、数字、结论都必须能在原文中找到依据。
- **不凑数**：信息不足时输出实际数量的卡片并注明，不会硬凑到 5 张。
- **暂不支持**：网页抓取、PDF、Anki 和图形界面。

## 安装方法

本项目为**纯指令型 Skill（无脚本、无运行时依赖）**，不需要安装任何 Python 包。

1. 将本仓库的 `skills/make-knowledge-cards/` 目录复制到你的 AI 助手可加载技能的目录，例如：
   - Anthropic Claude Code / Claude Skills：`~/.claude/skills/make-knowledge-cards/`
   - OpenAI Skills 格式：保留 `agents/openai.yaml`，将目录放入技能仓库即可被识别
   - 豆包等支持自定义技能的助手：放入平台的「用户技能 / 自定义技能」目录
2. （可选）校验 Skill 结构：运行官方 `quick_validate.py`：

   ```bash
   python <skill-creator-for-work>/scripts/quick_validate.py <skills>/make-knowledge-cards
   ```

   预期输出：`Skill is valid!`

## 使用方法

1. 向 AI 提供文章：直接粘贴文本，或上传本地 `.md` / `.txt` 文件。
2. 说“把这篇转成知识卡片”即可。
3. AI 输出 5~8 张知识卡片；若原文信息量有限，会输出少于 5 张并在开头注明。

## 输入输出示例

**输入**（用户粘贴的文章）：

> 光合作用是绿色植物利用光能，将二氧化碳和水转化为有机物并释放氧气的过程，主要发生在叶绿体中。光合作用分为光反应和暗反应两个阶段。光反应在叶绿体的类囊体薄膜上进行，需要光照，分解水产生氧气，同时生成 ATP 和 NADPH；暗反应在叶绿体基质中进行，不需要光，利用光反应产生的 ATP 和 NADPH 将二氧化碳固定并还原为糖类等有机物。影响光合作用速率的主要因素有光照强度、二氧化碳浓度和温度。

**输出**（AI 生成的知识卡片）：

```markdown
# 知识卡片：光合作用

## 卡片 1：光合作用的定义
- **核心知识**：光合作用是绿色植物利用光能，将二氧化碳和水转化为有机物并释放氧气的过程，发生在叶绿体中。
- **简明解释**：植物像一个能量转换器，把光能转化为储存在有机物里的化学能；原料是二氧化碳和水，产物是有机物和氧气。
- **例子或自测问题**：自测：光合作用的原料、产物和场所分别是什么？

## 卡片 2：光反应
- **核心知识**：光反应发生在叶绿体的类囊体薄膜上，需要光照，分解水产生氧气，并生成 ATP 和 NADPH。
- **简明解释**：光反应是光合作用中“靠光”的阶段：必须有光才能进行，水在这里被分解并放出氧气，同时把光能转化为 ATP 和 NADPH。
- **例子或自测问题**：自测：光反应在哪里进行？产生了哪些物质？

## 卡片 3：暗反应
- **核心知识**：暗反应发生在叶绿体基质中，不需要光，利用光反应产生的 ATP 和 NADPH 将二氧化碳固定并还原为糖类等有机物。
- **简明解释**：暗反应是“不靠光”的阶段，用光反应供应的能量把二氧化碳一步步变成糖类等有机物。
- **例子或自测问题**：自测：暗反应需要的能量从哪里来？

## 卡片 4：影响光合作用速率的主要因素
- **核心知识**：光照强度、二氧化碳浓度和温度是影响光合作用速率的主要因素。
- **简明解释**：光照越强、二氧化碳浓度越高，速率越快；但光照强度过高时速率趋于稳定，温度过高或过低都会抑制光合作用。
- **例子或自测问题**：例子：正午光照过强时，光合作用速率不会无限上升，而是趋于稳定。

## 卡片 5：光合作用的意义
- **核心知识**：光合作用对维持大气中的氧气含量至关重要，并为几乎所有的生命活动提供物质和能量来源。
- **简明解释**：绿色植物通过光合作用持续向大气补充氧气，同时把光能固定进有机物，供几乎所有生命活动使用。
- **例子或自测问题**：自测：为什么说没有光合作用，绝大多数生命活动就难以维持？
```
